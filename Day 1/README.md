# Week 3 - Day 1: Introduction to LLMs and Groq API

## Overview

This project is part of the Week 3 AI Engineering training and focuses on understanding the fundamentals of Large Language Models (LLMs) and interacting with them using the Groq API. The project demonstrates how to securely configure API credentials, send prompts to different LLMs, control model behavior using generation parameters, and process the responses returned by the API.

The implementation also includes a reusable wrapper function that will be extended and reused throughout the remainder of the training program.

---

## Learning Objectives

* Understand the AI landscape, including AI, Machine Learning, Deep Learning, and Generative AI.
* Learn the fundamentals of Large Language Models (LLMs).
* Understand tokens, context windows, and next-token prediction.
* Learn how Groq provides high-speed inference for open-source language models.
* Make API calls using the Groq Python SDK.
* Configure environment variables securely using `python-dotenv`.
* Experiment with different model parameters such as temperature and maximum output tokens.
* Compare responses generated by different Groq-hosted models.

## Features Implemented

### Secure API Configuration

* Loads the Groq API key using environment variables.
* Keeps sensitive credentials outside the source code.

### First LLM API Call

* Sends prompts to Groq-hosted language models.
* Receives and prints model-generated responses.

### Temperature Comparison

* Executes the same prompt multiple times using different temperature values.
* Demonstrates deterministic versus creative responses.

### Reusable `ask()` Function

* Encapsulates the API call into a reusable function.
* Supports:

  * Custom prompts
  * Optional system messages
  * Model selection
  * Temperature control
  * Maximum output tokens

### System Prompt Testing

* Uses system instructions to influence model behavior.
* Tests JSON-only responses.

### Model Comparison

Compares:

* `llama-3.3-70b-versatile`
* `llama-3.1-8b-instant`

The comparison includes:

* Response quality
* Prompt tokens
* Completion tokens
* Total tokens
* Latency
